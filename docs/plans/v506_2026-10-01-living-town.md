## Goal and dependencies

Add a small set of client-only ambient residents to the live level-0 town, with data-defined idle and slow walk/pause activity. Preserve the current service positions, terrain/dressing, actor/player readability, deterministic gameplay, and v500 render budget.

The prerequisite is the integrated v500 town dressing and its performance fixture, present in this worktree. No sibling slice is a functional prerequisite. v507 may inspect the same class-presentation assets; keep those catalogs read-only. v503/v504 may update the global asset manifest, but this slice plans no new asset registrations. `docs/CODEMAP.md` is a known shared documentation hotspot; report the exact hunk for coordinator resolution if another slice also updates it.

The only product assumption is documented in the spec: use existing KayKit hero bodies as anonymous townsfolk because no dedicated NPC models are present. If real-renderer inspection makes that visibly unsuitable, stop before expanding scope to external assets and report the concrete issue.
