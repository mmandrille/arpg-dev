## 3. Cross-cutting themes

- **The client boundary is healthy.** Inventory, skills, and fog presentation use existing authoritative item, progression, and wall-layout data. The only rules change is a wall added to the LOS test world.
- **Evidence varies by claim.** `make ci` and focused tests establish deterministic code paths. Screenshots are committed and useful, but the dark T-wall capture does not establish readability, and no performance A/B was run.
- **Small helpers are working.** Thumbnail caching, skill styles, and fog polygon layering have focused tests. The maintainability ratchets pass; further work should continue shrinking touched files.
- **Ownership remains the recurring maintenance cost.** `main.gd:_apply_delta`, `sim.go`, `validate_shared.py`, tooltip content, and the UI-theme migration are persistent seams.
- **The accepted UI scope is only partly complete.** Inventory and skill tree improved; character sheet remains a separate future slice.

## 4. Top 10 recommendations

Classifications: **[minor-commit]** safe paydown during `$refactor`; **[future-plan]** needs a larger design/implementation plan; **[future-slice]** player-facing acceptance or runtime proof.

1. **[future-plan · High] Make input acceptance durable before the simulation consumes it.** Define client-facing failure semantics and test failed append through replay. `server/internal/realtime/session_loop.go:370-395`, `session_tick.go:12-22`.
2. **[future-plan · Med] Bound replay work and propagate cancellation.** Choose a supported horizon and test large-tick rejection and canceled runs. `server/internal/replay/replay.go:262-295`, `server/internal/http/inspect.go:180-189`.
3. **[future-plan · Med] Pin replay rules/content and debug inputs.** Ensure reconstruction does not depend on the current process configuration. `server/internal/game/sim.go:511-523,898-904`.
4. **[future-slice · Med] Improve and capture T-wall face readability.** The current capture is too dark; deterministic geometry coverage is already established in v520.
5. **[future-plan · Med] Measure fog geometry/cache cost.** Profile representative wall layouts and movement before adding per-layout caching; no regression is proven.
6. **[future-plan · Med] Finish `UiTheme` adoption and unify item tooltip content.** Migrate panel by panel while retaining token coverage.
7. **[future-plan · Med] Extract a typed ordered router from `main.gd:_apply_delta`.** Add event-order/state-sync coverage before further hooks.
8. **[future-slice · Med] Propose a character-sheet redesign slice.** It was part of the broader UI direction but not one of the accepted v518–v520 slices.
9. **[minor-commit · Low] Make `UiTheme` literal-token discovery recursive and test nested scripts; add `boss_bar_frame.gd` to CODEMAP.** `tools/validate_ui_theme.py:38-44`, `docs/CODEMAP.md:33`.
