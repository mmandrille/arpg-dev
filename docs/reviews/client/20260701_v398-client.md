## Summary

The Godot client remains a credible **thin renderer**: intents out, authoritative snapshots/deltas in, presentation-only side effects. **v398** is the strongest recent slice architecturally — reconnect logic is extracted into `connection_recovery.gd`, `connection_recovery_runtime.gd`, and `connection_overlay.gd`, with data-driven backoff in `shared/rules/main_config.v0.json` → `client_reconnect`.

v384 paydown themes **mostly closed**: attack-move cluster extracted (`attack_move_input_coordinator.gd`), orphan smoke tests dropped 8→3, perf unit gaps closed (LOD, projectile cap, delta coalesce, recon backpressure in `client_smoke.sh`).

Regression vs v384 is **`main.gd` net growth (+188 lines)** despite extractions — panel god-files also crept (`inventory_panel.gd` 1,612; `shop_panel.gd` 1,239). v398’s highest-risk gap is **no E2E bot proof** for mid-game WS drop — unit-tested state machine only; bot/replay modes bypass recovery (`connection_recovery_runtime.gd:54–55`).
